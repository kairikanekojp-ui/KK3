# 稼ぐための毎日の型(月100万円に向けて)

## 数字の目標
- 毎日: 店探し→DM 30通(個別化必須) / 返信対応 / 3日前のDMにフォロー1回
- 週: 210通 → 返信4〜5件 → 面談・提案2件 → 受注1件前後
- 受注はプレミアム(15万)とスタンダード(10万)を主役に。保守(月5,000円)は全員に提案
- 月100万円 ≒ 15万×4 + 10万×3 + 保守を積み上げ。3か月目に達するには2か月目までに累計8件が目安

## 1.5万円の使い道(使う前に本人が決済)
- ドメイン・サーバー(見本サイト) 3,000円 / 素材・ツール 2,000円 / 予備 10,000円
- 広告は使わない(1万円では検証にならない)

## 作業の流れ
1. Googleマップ・Instagramで「地域名+美容室/ネイル/エステ」を検索。HPなし・古い店を選ぶ
2. prospects_sample.csv をコピーして prospects.csv に記入(良かった点は店ごとに具体的に)
3. `python3 make_dm.py prospects.csv --track` で個別DM案と tracker.csv 追記
4. DMはアカウントの利用規約の範囲で、手で送る(自動送信はアカウント停止の恐れあり)
5. 返信は dm_templates.md の返信テンプレ → 提案書 proposal.md → 契約 contract.md → 前金50%

## 受注を増やす工夫
- 先にその店専用のサンプルサイトを作って見せる(成約率が上がる)。ただし1日3店まで
- 最初の2件だけ割引+事例掲載条件。以降は定価
- 納品後に紹介依頼(紹介1件につき次回保守1か月無料など)
- 「成果を保証」はしない(景表法)
